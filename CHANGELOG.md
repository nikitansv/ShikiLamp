### Реализовано
- Запуск настоящей Lampa с плагином: `npm run test:lampa`, живые изображения, поиск и настройки без подмены host API.

### Исправлено

- Сохранённые ссылки постеров TMDB используют текущее зеркало Lampa; ошибки всех источников показывают название вместо пустого изображения.
- Возврат из меню аккаунта и окна OAuth в настройки; размер страницы меняется штатным списком с обновляемым значением.
- Обработчики SettingsApi учитывают передаваемое значение: видимость меню и плавность применяются сразу; сброс оформления сохраняет выбранную плавность.
- Инициализация после готовности Lampa, повторная загрузка плагина, применение настройки видимости меню.
- Запоздалые ответы прежнего аккаунта, отмена очереди запросов, таймаут fetch и повторное обновление уже обновлённого токена.
- Повторная загрузка поиска и каталога после сетевой ошибки, сохранение фокуса и отмена ввода.
- Поиск по числовому Shikimori ID и применение выбранного языка названий.
- Очередь и таймаут TMDB-поиска; повреждённые локальные данные и ошибки сохранения mappings.
- Маскирование credentials в консоли и диагностическом отчёте, экранирование текста ошибок.
- Единая команда `npm run check`, проверка готовой сборки и GitHub Actions для push/PR.
- Инструменты разработки обновлены: Jest 30.5.2, esbuild 0.28.2 и совместимые транзитивные зависимости; аудит npm не обнаружил уязвимостей на момент проверки.

### Ограничения
- OAuth выполняется в клиенте; токены и client credentials хранятся локально, а client secret включён в клиентский код. Backend-посредника нет.
- Browser mock не подтверждает работу на реальном телевизоре, WebView или пульте.
- Совместимость зависит от CORS, сети, mixed content и внутренних API Lampa.

## 0.1.0 — MVP

### Добавлено
- Раздел Shikimori в главном меню Lampa.
- Главный экран с разделами: Популярное, Онгоинги, Недавно вышедшее, Анонсы, Поиск, Локальные соответствия, Диагностика.
- Поиск аниме по русскому, английскому, оригинальному названию и Shikimori ID.
- Карточка аниме с описанием, типом, статусом, рейтингом, жанрами, студиями.
- Локальное хранилище соответствий Shikimori ↔ TMDB.
- Автоматический поиск соответствия через `Lampa.Api.search` со скорингом.
- Ручной выбор соответствия TMDB с указанием сезона и смещения эпизодов.
- Открытие стандартной карточки Lampa (`Lampa.Router.call('full', ...)`).
- Настройки плагина в Lampa SettingsApi.
- Локальный TTL-кэш для API-запросов.
- Диагностический экран с тестами API, GraphQL, поиска и экспортом отчёта.
- Экспериментальный access token (выключен по умолчанию, скрыт, не логируется).
- Unit-тесты для normalizer, cache, scoring, matcher.

### Известные ограничения
- Нет OAuth и синхронизации прогресса просмотра.
- Автоматический mapping зависит от доступности `Lampa.Api.search`.
- Прямой доступ к `shikimori.io` из браузера может быть ограничен CORS / User-Agent / mixed content.
- Плагин рассчитан на локальную сеть; без LAN-proxy может не работать в некоторых WebView.

### Планы на момент выпуска
- OAuth-авторизация Shikimori через пользовательский backend или локальный proxy.
- Синхронизация просмотренных эпизодов с Shikimori.
- Улучшенный matching с учётом MAL ID и TMDB find-by-external-id.
- Поддержка списков пользователя (planned, watching, completed).
- Интеграция с локальным LAN-proxy для обхода CORS при необходимости.
